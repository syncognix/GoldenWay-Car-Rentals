# On-the-lot media

Source: GoldenWay Car Rentals' own Facebook page — https://www.facebook.com/goldenwaycarrentals/
(retrieved Oct 2026, supplied for use on this site by the business).

- `lot-*.webm` / `lot-*.jpg` — text-free segments cut from the page's reels, slowed down
  (0.35–0.45×) and re-encoded to 540×960 VP9 loops; the `.jpg` is each clip's first frame.
  - lot-camry-side, lot-camry-hood — white Toyota Camry walk-around
  - lot-impreza, lot-impreza-cabin — silver 2020 Subaru Impreza
- `../images/lot-*.jpg` — un-captioned photos from the page's photo grid.
- `../fleet/subaru-impreza-2020/01.jpg` — still frame of the actual Impreza from the same reel.

Original white-background stock photos that were replaced by transparent cutouts are kept in
`../_source/fleet/` (not picked up by the media registry).
